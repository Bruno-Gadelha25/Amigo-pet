# 🐶 Amigo Pet

Site moderno e responsivo desenvolvido para um pet shop, com design acolhedor e foco em conversão. Utiliza cores quentes com destaque em laranja, layout clean e navegação simples. Conta com seções de serviços, diferenciais, depoimentos e integração com WhatsApp para facilitar o contato e atrair novos clientes.

🔗 **Ver online:** https://amigo-pet-mu.vercel.app

## ✨ Destaques

- Layout **responsivo**, pensado primeiro para o celular
- Contato direto pelo **WhatsApp**, para converter visitante em cliente
- Animações suaves com **Motion** e ícones **Lucide**
- Página única, leve e com carregamento rápido via **Vite**

## 🛠️ Tecnologias

| Camada | Ferramenta |
|---|---|
| Interface | React + TypeScript |
| Estilo | Tailwind CSS |
| Animações | Motion |
| Build | Vite |
| Deploy | Vercel |

## ▶️ Como rodar localmente

```bash
git clone https://github.com/Bruno-Gadelha25/Amigo-pet.git
cd "Amigo-pet/amigo pets"
npm install
npm run dev
```

Acesse **http://localhost:3000**.

## 📁 Estrutura

```
amigo pets/
├── src/
│   ├── App.tsx      # página e seções
│   ├── main.tsx     # ponto de entrada
│   └── index.css    # estilos globais / Tailwind

```
